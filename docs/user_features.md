# User Features
Not all features require a server to use! Here are some features that you can use in private chats.

!!! info
    To use features in private chats, simply add Cookie to your Discord account.

---

## 🔔 Reminders
Set personal reminders using the `/reminder create` command.

- To view all your reminders, use `/reminder list`.

---

## 💬 Quotes
Generate quote images of messages.

- Simply right-click on a message and select `Apps > Create Quote` to generate a quote image.
- Customize your images using `/quote_settings`.
