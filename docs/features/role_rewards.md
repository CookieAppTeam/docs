# Role Rewards
Award users with a role for certain actions.

---

## 🏷️ Server Tag Rewards
Reward users that use your **server tag** with a role!

- Use `/settings` to set up server tag rewards.

---

## 🍻 Other Role Rewards
Here is an overview of other role rewards that Cookie offers:

| Reward Type                           | Description                                                                         |
|---------------------------------------|-------------------------------------------------------------------------------------|
| [**Birthday Role**](birthday.md)      | Assign a role to members on their birthday. Configure this in `/birthday_settings`. |
| [**Level Roles**](leveling.md)        | Assign roles based on user levels. Configure this in `/level settings`.             |
| [**Activity Reward Role**](banner.md) | Assign a role to the most active user. Configure this in `/banner`.                 |
