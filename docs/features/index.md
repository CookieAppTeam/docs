# Feature Overview
Here is a quick overview of Cookie's **main features**.
If you want to learn more, we have a dedicated page for each system.

---

## 📈 [Leveling](leveling.md)
Cookie has a built-in leveling system for **text** and **voice** activity.

- Configure the level system with `/level settings`.

---

## 🎟️ [Ticket System](tickets.md)
Create a ticket panel where users can create support tickets.

- Use `/ticket settings` to enable the ticket system in your server.

---

## 🔊 [TempVoice](tempvoice.md)
Allow users to create their own customizable voice channels!

- Use `/tempvoice setup` to get started.

---

## 🎉 [Giveaways](giveaway.md)
Host powerful giveaways on your server.

- Use `/giveaway create` to start a new giveaway.

---

## 🍰 [Birthday Notifications](birthday.md)
Send birthday notifications to your server members.

- Server members can set their birthday using the `/birthday` command.
- Moderators can use `/birthday_settings` to select a **channel** for birthday notifications.
